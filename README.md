# Temporal Super Resolution (TSR) PyTorch Model

This project extends the spatial Super-Resolution model into a basic **Temporal Super Resolution (TSR)** model. This helps us explore the concepts behind technologies like DLSS and PSSR, which use data from previous frames to resolve high-frequency details and stabilize the image.

## How it works without a Game Engine
Real upscalers use motion vectors generated by the 3D rendering engine. Because we are working with standard 2D image datasets, we generate a synthetic dataset. During training, the dataset script acts like a virtual camera panning slightly across a high-resolution image to generate two sequential frames (`Frame t-1` and `Frame t`).

The Neural Network architecture uses "Early Fusion" by stacking the RGB channels of the previous frame and current frame into a single 6-channel input before passing it into the ResNet blocks.


## How to Train

The training script automatically generates the simulated temporal dataset.

```bash
# To train for a few epochs locally
python3 src/train.py --epochs 5

# To train for high-quality production results on a GPU
python3 src/train.py --epochs 1000
```

## How to Run Inference

The inference script will automatically take an input image, simulate a 5-pixel camera movement to generate the previous and current frame, shrink them, and pass them into the TSR model.

```bash
python3 src/inference.py --checkpoint checkpoints/tsr_model_epoch_1000.pth --output assets/temporal_example_comparison.png
```

The resulting comparison image will show four panels: the offset previous frame, the current frame, bicubic scaling, and the TSR output.
